# Screenshots

Drop the images here and uncomment the matching block in `README.md` and
`README.es.md`. Both files already have the markup in place, commented out.

Worth capturing, in this order:

| File | What it should show |
|---|---|
| `dashboard.png` | The whole page, window past 50% so the strip chart has a real trace |
| `strip.png` | Just the window strip, with something queued so the blocks past the reset rule are visible |
| `compose.png` | The compose panel mid-typing, with the live forecast line showing what it costs and what it leaves |
| `terminal.png` | `tokio status` in a terminal |

Take them dark, at a width that keeps the text legible in a README — around
1400px works. A window that's nearly empty makes a boring picture; the tool
looks like itself when it's under pressure.
